# Documentación del proyecto

El plan de gestión (ISO 21500/21502, versión 0.2) vive en el documento en línea del proyecto. Aquí se guardan los registros técnicos:

- `adr/`: decisiones de arquitectura, una por archivo (`0001-...md`).
- Los demás documentos de gestión (acta, riesgos, cambios) se agregan aquí como `00-acta.md`, `03-riesgos.md`, etc., cuando se exporten del documento en línea.
